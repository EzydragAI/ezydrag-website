TL;DR

Inject one boring failure, like a timeout or an empty list, and agent success can drop by up to 50 points. Test the sad path before your customers do.

Timeline

Okay. So. I want to walk through this carefully, because it's, honestly, kind of terrifying, and also, weirdly, great news? Let me explain.

In August, a research team including David Lo published AgentChaos. It's chaos engineering for AI agents. They inject faults into the API responses agents depend on (crashes, missing data, wrong values) and watch what happens. No code changes needed.

They ran 65 fault setups.

Every single system they tested got worse.

50 points

How far success dropped, at worst, when the researchers broke one thing at a time.

Root cause

Here's the part I keep coming back to. System rankings stayed consistent across models. Which means (and I want to be careful here) how robust your agent is depends more on how it's built than on which model you picked. The harness is the main character. Not the model. The harness.

And finding out what went wrong is hard. Existing diagnosis methods got the fault type right less than 53% of the time. So you can't just, you know, debug your way out later.

Plot twist

Ten days after AgentChaos, Yintong Huo, Rangeet Pan and Abhik Roychoudhury argued for judging agents by their trajectory: every step, tool call and observation. They also shared a readiness checklist for deployment. Different paper, same conclusion.

Why you should care

Real tools fail in boring ways. Salesforce times out. Marketo returns nothing. A field is blank. An agent that only ever saw the happy path will guess its way through those moments. Confidently. That's the word that keeps me up at night.

Action items

  • Write the failure list first. Timeouts, empty results, duplicates, missing consent.
  • Decide the safe move. For a sales agent it's almost always: stop, and tell a person.
  • Budget for it. Our Chief Operating Officer's rule, and he's right: if testing failures isn't in the plan, it isn't in the price.

How we do it at Ezydrag

Before an agent touches live leads, we run it through the failure list in a test setup. A pass means it stopped and a person was told. Then we keep watching real runs, because production always finds something new. Even Salesforce now ships agent health monitoring out of the box. The whole industry is quietly admitting this is the hard part.
